Comandos Básicos de HTML

Aprendendo HTML de um jeito fácil!

O que é HTML?

HTML é uma linguagem usada para criar páginas da internet.

Principais comandos

1. Títulos

A tag <h1> cria um título.

2. Parágrafos

A tag <p> cria um parágrafo.

3. Negrito

A tag <strong> deixa o texto em negrito.

4. Imagens

A tag <img> adiciona uma imagem.

5. Links

A tag <a> cria um link para outro site.

6. Quebra de linha

A tag <br> pula uma linha.
